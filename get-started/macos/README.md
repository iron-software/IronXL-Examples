# Comprehensive IronXL Support for macOS with .NET Core

> Full guide: [Comprehensive IronXL Support for macOS with .NET Core](https://ironsoftware.com/csharp/excel/get-started/macos/)


IronXL is now completely compatible with macOS (_previously known as "OS X"_) for .NET Standard Libraries, Core applications, and .NET 5 projects, offering full support across all macOS versions right out of the box.

There is no need for any modifications in the code when targeting Apple users or developers.

The inclusion of macOS support is significant to us as numerous .NET developers, including those on our team, prefer developing .NET applications using _Visual Studio for Mac_ and _JetBrains Rider_ on macOS.

## Setup and Installation on macOS

Deployment to macOS using IronXL is seamless, facilitated by our NuGet packages detailed in our [IronXL NuGet installation guide](https://ironsoftware.com/csharp/excel/docs/).
